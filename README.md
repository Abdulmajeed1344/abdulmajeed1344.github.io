# Abdul Majeed — Portfolio Website

Personal portfolio for **Tachie-Menson Fiifi Abdul Majeed**, IT professional based in Accra, Ghana.

🌐 **Live site:** https://abdulmajeed1344.github.io

---

## Tech Stack

- **HTML5 / CSS3 / Vanilla JavaScript** — no framework needed
- **Custom particle canvas** — animated background reacting to mouse movement
- **Typewriter effect** — built from scratch (no library dependency)
- **Intersection Observer** — scroll-triggered section reveals
- **Google Fonts** — Playfair Display, IBM Plex Mono, Outfit

## File Structure

```
abdul-majeed-portfolio/
├── index.html       ← Main single-page layout
├── style.css        ← All styles & design tokens
├── script.js        ← Animations, particles, typewriter, cursor
├── cv.pdf           ← ⚠️ ADD YOUR CV HERE
└── README.md
```

## Before Going Live — Update These

1. **`cv.pdf`** — Drop your CV PDF in this folder. The "Download CV" button links to `cv.pdf`.
2. **GitHub links** — Update each project card's `href` in `index.html` with real repo URLs.
3. **LinkedIn** — Replace `href="https://linkedin.com/in/"` with your profile URL.

## Deploy to GitHub Pages

```bash
# 1. Initialize git inside this folder
git init
git add .
git commit -m "Initial portfolio commit"

# 2. Create a repo named: abdulmajeed1344.github.io
#    on github.com/Abdulmajeed1344

# 3. Push
git remote add origin https://github.com/Abdulmajeed1344/abdulmajeed1344.github.io.git
git branch -M main
git push -u origin main
```

GitHub Pages will automatically serve `index.html` at:
**https://abdulmajeed1344.github.io**
